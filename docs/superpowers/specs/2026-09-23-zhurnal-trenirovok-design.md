# Журнал тренировок — ТЗ

Редакция 15.10.2026 · программа «Фулбоди 3 дня» (Вт · Чт · Сб)

## 1. Цель

Мобильное приложение-дневник для программы «Фулбоди 3 дня в неделю», сезон 2026/27: в зале быстро записывать подходы, получать подсказку веса по правилам прогрессии, видеть тоннаж и рост весов.

Источник программы (эталон для тестов): `Программа тренировок 2026-27 3 дня.docx`.

Пользователь один. Интерфейс только на русском.

## 2. Платформа и стек

| Решение | Значение |
|---|---|
| Формат | PWA: устанавливается на главный экран Android и iPhone, работает полностью офлайн |
| Стек | Preact + TypeScript + Vite, `vite-plugin-pwa` (service worker, манифест) |
| Хранилище | IndexedDB через Dexie, только на телефоне; `navigator.storage.persist()` при первом запуске |
| Графики | собственные SVG-компоненты (`src/ui/Chart.tsx`); палитра проверена валидатором dataviz |
| Тесты | Vitest (логика и хранилище), ручной прогон в браузере в размере телефона |
| Хостинг | GitHub Pages, репозиторий `vik9123/trenirovki`; `npm run deploy` — тесты, сборка и выкладка `dist/` в ветку `gh-pages` |

Сервера нет. Код публичный, данные журнала не покидают телефон, кроме файла резервной копии, который пользователь сохраняет сам.

## 3. Программа (зашита в код)

Программа — неизменяемый модуль `src/program.ts`. Редактора нет; единственная вариация — замена упражнения из документа.

Каждое упражнение — «слот» с постоянным `id`, обычно равным ключу упражнения (`f3-…`); порядок в дне задаёт `order`. Если упражнение в слоте сменилось, `id` слота сохраняется, у нового упражнения — новый ключ (жим одной рукой в четверг: слот `f3-1arm-press`, основное `f3-1arm-machine-press`).

Поля слота: `id`, `day`, `order`, `exercise` (`key`, `name`, `equipment`, `muscles`, `technique?`, `perSide?`), `sets`, `repMin`, `repMax`, `progressTo?`, `restSec`, `substitutes?` (список замен).

Шаг веса по умолчанию (меняется в настройках):

| `equipment` | Шаг |
|---|---|
| `barbell` — штанга | +2,5 кг |
| `smith` — Смит | +2,5 кг |
| `dumbbell` — гантели (вес одной гантели) | +2 кг |
| `machine` — блоки и тренажёры | +5 кг |
| `added` — дополнительный вес (подтягивания, брусья) | +1,25 кг |

## 4. Модель данных (Dexie, версия 3)

| Таблица | Поля |
|---|---|
| `cycles` | `id`, `number`, `startedAt`, `currentWeek` (1-8), `finishedAt?` |
| `sessions` | `id`, `cycleId`, `week`, `day` (`tue`/`thu`/`sat`), `date`, `startedAt`, `finishedAt?`, `wellbeing?` (1-5), `back?` (`ok`/`ache`/`pain`), `note?` |
| `sets` | `id`, `sessionId`, `slotId`, `exerciseKey` (основное или замена), `index`, `weight`, `value` (повторения; на одну сторону — для четверга), `rir?`, `pain`, `done` |
| `bodyweight` | `id`, `date`, `kg` |
| `settings` | шаги по снарядам, звук, дата последней резервной копии |

Версия 3 при обновлении стирает прежние циклы и тренировки (журнал начинается с нуля под эту программу); вес тела и настройки сохраняются.

Тоннаж подхода = `weight × value` для выполненных подходов; хранится не он, а подходы.

## 5. Логика цикла

- Следующая тренировка: день, совпадающий с сегодняшним (Вт/Чт/Сб), если он не сделан; иначе первый несделанный. Начать можно любой несделанный день.
- Когда сделаны все 3 дня — неделя переключается сама; «Перейти к следующей неделе» — при пропусках. После недели 8 — «Начать новый цикл».
- Цикл 1, неделя 1 — калибровка: 4 подхода → 3 (63 подхода). Недели 2-7 — 76. Неделя 8 — разгрузка, по 2 подхода (42). Цикл 2+ — без калибровки.

## 6. Подсказки прогрессии

«Прошлый раз» — последняя завершённая тренировка с этим `exerciseKey`, кроме недели разгрузки. Верх набран — все запланированные подходы выполнены и `value ≥ progressTo ?? repMax`.

| Ситуация | Вес | Повторения | Подсказка |
|---|---|---|---|
| Нет истории | 0 | `repMin` | «Калибровка: подберите рабочий вес» |
| Разгрузка | прошлый | прошлые | «Разгрузка: веса те же, подходов меньше» |
| Боль ⚡ в прошлый раз | прошлый | прошлые | «В прошлый раз была боль — держим вес» |
| Тяжёлый день, верх набран | + шаг | `repMin` | «Верх набран → +2,5 кг» |
| Тяжёлый день, верх не набран | прошлый | прошлые | «Держим вес, добиваем до N» |
| Лёгкий день, верх набран | + шаг | `repMin` | «Верх набран → +2 кг, назад к N» |
| Лёгкий день, верх не набран | прошлый | прошлые | «Держим вес, +1 повтор» |
| Разведения (`progressTo: 20`) | до 20 повторений вес держим, на 20 — + шаг и назад к `repMin` | | «Держим вес, +1 повтор (до 20)» / «20 повторений набраны → +2 кг, назад к 12» |

Каждая замена ведёт свою историю (ключ `…~sub`, `…~sub2` или свой) и свой шаг; в следующий раз подставляется то упражнение слота, что делали последним. Кнопки: «Заменить на «…»» для каждой замены и «Вернуть «основное»».

## 7. Экраны

Сегодня · Тренировка · История · Прогресс · Ещё (вес тела, резервная копия, шаг веса, звук). Тёмная тема, крупные элементы.

## 8. Таймер и надёжность

Отдых по `restSec`, после последнего подхода — 90 с перехода; время — от отметки окончания. Звук, вибрация (Android), экран не гаснет. Каждое изменение сразу пишется в базу.

Резервная копия — JSON `trenirovki-backup-ГГГГ-ММ-ДД.json`, `schemaVersion: 2`. Копии прежнего формата (`schemaVersion: 1`) и копии с неизвестными упражнениями не восстанавливаются.

## 9. Тесты

Программа сверяется с документом (состав, подходы, диапазоны, отдых, 76 в неделю); недели цикла; все ветки прогрессии; тоннаж; выбор дня; хранилище; замены; обновление базы v3; резервная копия.
