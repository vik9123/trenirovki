# Журнал тренировок

Мобильное приложение-дневник для программы «Сплит верх/низ, тяжёлый и лёгкий день», сезон 2026/27.
Работает без интернета, данные хранятся только на телефоне.

**Открыть:** https://vik9123.github.io/trenirovki/

## Установка на телефон

**Android (Chrome):** откройте ссылку → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

**iPhone (Safari):** откройте ссылку именно в Safari → кнопка «Поделиться» □↑ → «На экран „Домой“» → «Добавить».

После установки приложение открывается с иконки на главном экране, как обычное, и работает без интернета.

## Как пользоваться

1. **Сегодня** — нажмите «Начать». Приложение предлагает тренировку по дню недели, но можно начать любую несделанную.
2. **Тренировка** — у каждого подхода вес и повторения уже подставлены по прошлому разу и правилам прогрессии.
   Поправьте кнопками «−/+» (или нажмите на число и введите), отметьте запас повторений и ⚡ боль, если была, нажмите ✓ —
   запустится таймер отдыха. В конце — «Завершить» и самочувствие.
3. **Прогресс** — тоннаж по неделям (как лист «Сводка») и график рабочего веса по каждому упражнению.
4. **Ещё** — вес тела, резервная копия, шаг веса для подсказок.

Неделя переключается сама, когда сделаны все 4 дня. Если тренировку пропустили — «Перейти к следующей неделе».

## Резервная копия — раз в неделю

Журнал хранится только на телефоне. Если удалить приложение или очистить данные браузера — записи пропадут.
«Ещё» → «Сохранить копию» → сохраните файл в «Файлы», облако или отправьте себе.
Восстановление: «Ещё» → «Восстановить из файла». Главный экран напомнит, если копии не было больше недели.

## Особенности iPhone

- Вибрации в конце отдыха нет (Safari её не поддерживает) — только звук. Проверьте, что телефон не в беззвучном режиме.
- Если заблокировать экран, таймер продолжит считать и покажет верное время после разблокировки, но сигнал прозвучит, только если приложение открыто.

## Разработка

```bash
npm install
npm test        # тесты логики и хранилища (Vitest)
npm run dev     # локальный сервер
npm run build   # сборка в dist/
npm run deploy  # тесты, сборка и публикация в ветку gh-pages
```

Программа зашита в `src/program.ts`, правила — `src/logic/`, хранилище — `src/data/`.
Документы: `docs/superpowers/specs/` (ТЗ), `docs/superpowers/plans/` (план).
Публикация — `npm run deploy`: готовая сборка уходит в ветку `gh-pages`, GitHub Pages раздаёт её.
